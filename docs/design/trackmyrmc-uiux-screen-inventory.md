# TrackMyRMC UI and workflow review matrix

Baseline is the draft PR #209 tree at `79dfc02f0af6abd13899792336689735dc640be0` on top of main `ce67a8d6a1a96d8f6da3ae13fd139918c818edfa`, with the changes in this PR applied.

The Expo table inventories actual route source files and follows direct imports of shared screens. Dependencies and state markers are source signals for triage. A blank signal can mean the behavior lives in a shared component or an indirect API method. The flags identify places to inspect at runtime. Each route still requires representative native and integration acceptance unless that evidence is recorded separately.

Baseline visual direction uses Jakarta and orange on graphite or warm surfaces. This increment retains the existing subdued image assets and keeps the order form on readable solid or nearly opaque surface layers. The audit found fixed dimensions, capped labels, and screens with local Back calls that deserve narrow screen, enlarged type, dialog, keyboard, and deep-link testing. Browser fixture coverage exercises representative routes rather than every action.
